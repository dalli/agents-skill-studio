# Agent Skill Studio — 설계 문서

> [Agent Skills](https://agentskills.io) 표준(원래 Anthropic이 공개한
> open standard)의 전체 수명주기 — **작성 → 검증 → 테스트 → 패키징 →
> 설치 → 임포트** — 를 다루는 데스크톱 애플리케이션의 설계 문서 모음.
>
> **이 문서들의 기준이 되는 요구사항** —
> [PRD](../.omx/plans/prd-agent-skill-studio.md) (영어, 52개 AC).
> PRD가 **원본**이며 이 문서들은 그 설계를 한국어로 정밀화한다.
> 영문 인용이 필요하면 PRD를 본다.

## 문서 간 참조 규칙

이 모음의 **중복 방지 메커니즘**이다. 내용을 두 곳에 쓰면 그 두 곳은
서로 다른 시점에 수정되어 반드시 어긋난다.

| 규칙 | 내용 |
|---|---|
| **단일 소유** | 각 정의는 정확히 한 문서가 소유한다 |
| **링크로 대체** | 다른 문서는 링크한다. 재정의하지 않는다 |
| **추적성은 04 단독** | AC → 설계 → 단계 매트릭스는 04에만 존재한다 |

### 소유권 표

| 정의 | 소유 문서 | 다른 문서의 역할 |
|---|---|---|
| `SkillFrontmatter` 등의 **필드** | 02 | 01은 "존재"를 언급하고 링크 |
| 검증 **규칙의 이유** | 01 §4.3, 02 §3 | 03은 "무엇을 표시할지"만 |
| 데이터 모델 **이름** | 00 §3 (규약) | 전 문서가 00을 따름 |
| 컴포넌트 **ID** `C1`–`C12` | 00 §2 | 전 문서가 사용 |
| 화면 **ID** `S1`–`S9`, `O1`–`O5` / 스파이크 `SP-1`–`SP-4` | 00 §4 | 03이 상세 설계 |
| **AC 매트릭스** | 04 §10 | 다른 문서는 "04 참조" |
| 아키텍처 결정 `A-n` | 01 §2 이하 | 04가 태스크에 매핑 |
| 데이터 규칙 `D-n` | 02 | 04가 검증에 매핑 |

## 핵심 결정 요약

전체 상세는 각 문서에 있다. 여기서는 **왜 그런지**만 한 줄로.

| 결정 | 이유 | 상세 |
|---|---|---|
| Tauri v2 + Python 사이드카 | 파일 접근·프로세스 지배는 Rust에, 규칙은 Python에. **규칙의 단일 진실 공급원** | [01 §3](./01-architecture.md#3-프로세스-아키텍처-c1--c2) |
| `skills-ref`를 **개발 의존성으로만** | 그 라이브러리가 스스로 production 용도를 거부한다. 규칙이 **데모 코드에만** 존재 | [01 §2.4](./01-architecture.md#24-스펙-준수-증명-conformance-before-features) |
| **차분 준수 하네스** | 스펙이 JSON Schema를 배포하지 않는다. 드리프트를 **빨간 빌드**로 바꾼다 | [04 §4.2](./04-development-plan.md#42-핵심-태스크-상세) |
| **본문도 실행 표면** | `` !`cmd` `` 가 모델 전달 **전에** 셸 명령을 실행한다. `scripts/` 없는 스킬도 위험 | [01 §7.2](./01-architecture.md#72-본문도-실행-표면이다) |
| 정적 분석이 샌드박스보다 **먼저** | 실행 없이 가능한 검사는 전부 정적으로. `C5`는 `SP-1`에 의존하지 않는다 | [01 §2.3](./01-architecture.md#23-정적-우선-static-before-dynamic) |
| **실패-닫힘** | 샌드박스 실패 시 무격리 실행은 "샌드박스 없음"과 구별되지 않는다 | [01 §2.2](./01-architecture.md#22-실패-닫힘-fail-closed) |
| 프로필은 **규칙 엔진 하나** | `strict`/`lenient`를 두 번 구현하면 반드시 drift한다 | [02 §3.7](./02-data-design.md#37-프로필--하나의-규칙-엔진-하나의-심각도-맵) |
| **유니코드 `name` 허용** | `isalnum()`은 유니코드를 인식한다. ASCII 하드코딩은 한국어 스킬을 거부한다 | [02 §3.2](./02-data-design.md#32-name-검증-규칙--유니코드와-nfkc) |
| **"미지의 키"는 3분류** | 알려진 클라이언트 확장(14개)과 오타를 구별해야 정상 스킬을 지우라고 안내하지 않는다 | [02 §4.2](./02-data-design.md#42-keyclassification-3분류) |
| **"설치 성공" = "클라이언트가 찾는다"** | 예약 이름·섀도잉은 **조용히** 로드를 막는다 | [01 §8.3](./01-architecture.md#83-설치-성공이-거짓말이-되는-4가지-경우) |
| 재현성은 **테스트로 증명** | 테스트하지 않으면 재현성은 주장이지 기능이 아니다 | [04 §5.1](./04-development-plan.md#51-병렬-그룹-a--c10-packager-가장-먼저-시작) |
| `stddev`는 `0`이 아니라 **`None`** | 1회 실행에서 `0.0`은 "편차 없음"을 **거짓 주장**한다 | [02 §7.9](./02-data-design.md#79-benchmark--metricstats--benchmarkdelta) |
| 결정론적 체커가 LLM 판정보다 **먼저** | "기계 검사가 LLM 판단보다 신뢰할 만하다"를 **검증 가능**하게 만든다 | [02 §7.5](./02-data-design.md#75-채점-파이프라인--결정론적-우선) |
| 3분할 + 최소 880px | 편집기 폭이 곧 가독성. 좁은 화면을 예쁘게 만들지 말고 **기능을 명시적으로 제한**한다 | [03 §3.2](./03-ui-design.md#32-최소-창-크기) |
| **"0개"와 "없음"을 구별** | 진단 0개(성공)와 검증 대상 없음(미실행)은 비어 있으나 의미가 다르다 | [03 §6.1.1](./03-ui-design.md#611-빈-상태--4가지-구별) |
| `unverifiable`은 **중립 회색** | `pass`도 `fail`도 아니다. 판정기가 자신을 신뢰 못 한 상태 | [03 §7.5.1](./03-ui-design.md#751-3상태-시각적-구분) |

## 이 설계가 감수하는 위험

**전환 가능한 문서로 적어 둔다.** 뒤에서 무너지는 것보다 앞에 쓰는 편이 낫다.

| 위험 | 영향 | 처리 | 문서 |
|---|---|---|---|
| **샌드박스 불가** | L2 동적 실행 상실 | **정적 분석 전용으로 축소.** 좁지만 거짓말쟁이가 아닌 제품으로 | [04 §2.2](./04-development-plan.md#22-sp-1-결과에-따른-분기--완료-정의와의-충돌을-정면으로-다룬다) |
| **Windows 소켓 미검증** | 전송 계층 분기 | loopback TCP 폴백 (플러그인화) | [01 §3.3](./01-architecture.md#33-전송-계층) |
| **스펙 드리프트** | 검증기가 조용히 뒤처짐 | 차분 하네스 → 빨간 빌드 | [01 §11](./01-architecture.md#11-열린-이슈) |
| **유니코드 `name` 모호성** | 한국어 스킬 수용 여부 | 참조 구현을 따르고 불일치를 진단으로 노출 | [02 §14](./02-data-design.md#15-열린-이슈) |
| **UTF-16 오프셋 오류** | 한글 위치 밀림 | 스파이크로 선행 확인 + **수동 QA 필수** | [03 §13.2](./03-ui-design.md#132-수동-검증-playwright로-어려움) |
| **LLM 채점 비결정·비용** | flaky 보고서·비용 폭주 | 결정론적 우선, `MockAdapter` CI, 비용 사전 표시 | [04 §7](./04-development-plan.md#7-단계-4--c7-eval-engine--c8-runadapter) |
| **클라이언트 확장 증가** | 레지스트리 뒤처짐 | 레지스트리를 **데이터**로 유지 | [02 §4.3](./02-data-design.md#43-레지스트리는-코드가-아니라-데이터) |
